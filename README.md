## 🚀 Key Highlights & Projects

* **Zapex-med**: Study material portal with a searchable subject library, student accounts, private document reader, and administrative management dashboard (Next.js, React, TypeScript, Tailwind CSS, PostgreSQL, Prisma, Cloudflare R2).
* **Nehal & Ariba Wedding Invitation**: Digital wedding experience with animated reveal, interactive countdown, itinerary directions, music, and validated WhatsApp RSVP (React, TypeScript, Vite, Tailwind CSS).
* **Replora CRM & WhatsApp AI Agent**: Full-featured customer relationship management and automated follow-up platform with live webhook dispatch to n8n workflows, chat simulation, lead lifecycle kanban, and Google Calendar scheduling (JavaScript, HTML5, CSS3, n8n, WhatsApp Webhook API).
* **MOIL Laptop Reimbursement Application**: Enterprise workflow system translating organizational policies into technical processes for MOIL Limited (Systems Department).
* **QuickWA**: Android utility for initiating WhatsApp conversations without saving contacts to phone storage (Flutter, Dart).
* **Road Lane Detection**: Computer vision experiment processing driving video footage to identify and overlay lane boundaries (Python, OpenCV, NumPy).
* **Restaurant Management Application**: Operational tool for order tracking, menu coordination, and billing workflows (TypeScript, React, HTML, CSS).

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/izhaanzia/portfolio-v2.git
   cd portfolio-v2
   ```

2. **Serve locally**:
   Because the portfolio uses standard HTML, CSS, and modern JavaScript modules, you can serve it with any static web server:
   ```bash
   # Using Python 3
   python3 -m http.server 3000

   # Or using Node / npx
   npx serve .
   ```

3. Open `http://localhost:3000` in your browser.
