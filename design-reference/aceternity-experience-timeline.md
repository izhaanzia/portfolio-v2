# Experience timeline

Reference: https://ui.aceternity.com/components/timeline and the user-supplied TimelineDemo.

The portfolio is a static HTML site. The timeline is adapted natively in journey-sawad.css/js, retaining sticky year labels and a scroll-driven vertical beam without introducing React, Tailwind or Motion runtime dependencies. It replaces the previous pinned horizontal journey.

Actual content only: MOIL internship (June 2026–present), ByteUprise internship (April–May 2025), and B.Tech CSE (2024–2028). The MOIL image is the existing actual project capture. Reduced motion shows all content immediately; no-JS remains readable.
