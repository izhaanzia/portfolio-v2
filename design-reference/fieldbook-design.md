# Izhaan Zia — fieldbook direction

The portfolio is a personal record of practical web, workflow, and automation work. Preserve the existing projects, contact information, portrait, résumé, and Android download.

Palette: deep teal #101c20, mineral #263c40, paper #f0ede5, muted sage #adb5ad, peach #e5b39a. Retain Instrument Serif for personal, expressive display type and Schibsted Grotesk for reading and controls.

Layout: left-aligned oversized name beside an arched portrait panel; asymmetric project grid with large first and final projects; compact mini-project archive; generous readable biography, experience, and contact sections. Use space and contrast rather than decorative numbering or fake metrics.

Motion: one GSAP entrance timeline; pointer-responsive portrait spotlight adapted from ibelick's Spotlight on 21st; brief filter and dialog feedback. No automatic marquee, scroll hijacking, or perpetual movement. All content is visible without JavaScript and under reduced motion.

Sources:
- Frontend Design local skill
- UI UX Pro Max: storytelling structure and progressive motion guidance
- GSAP core, timeline, performance skills; https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/
- Spotlight by ibelick: https://21st.dev/@ibelick/components/spotlight (adapted from React/Framer Motion to vanilla JavaScript and GSAP)
